This is a sample post so you can see how the blog looks. Replace it with your first real one, or delete this file.

Every `.mdx` file in `src/content/blog/` becomes a post. The file name is the URL, so this one lives at `/blog/hello-world`. Posts show up in the news feed on the homepage automatically.

## Writing a post

Put a little frontmatter at the top of the file:

```
---
title: Your title
date: 2026-11-22
description: One line for the blog index and link previews.
---
```

Add `draft: true` to keep a post hidden while you work on it.

> Pull quotes look like this.

After that it's just Markdown, plus any React component you want to import.
